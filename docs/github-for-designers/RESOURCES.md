# GitHub workflow Resources

## Knowledge

- [GitHub Docs: "GitHub flow"](https://docs.github.com/en/get-started/using-github/github-flow)
  The six-step branch → commit → PR → review → merge → delete loop this course is built on. Use for: the overall workflow.
- [GitHub Docs: "Hello World"](https://docs.github.com/en/get-started/start-your-journey/hello-world)
  Web-only walkthrough of a first branch and PR. Use for: designers who want to try the loop in the browser before the terminal.
- [GitHub Docs: "Reviewing proposed changes in a pull request"](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/reviewing-changes-in-pull-requests/reviewing-proposed-changes-in-a-pull-request)
  Line comments, suggested changes, Comment / Approve / Request changes. Use for: the review step.
- [GitHub Docs: "About pull request merges"](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/incorporating-changes-from-a-pull-request/about-pull-request-merges)
  Merge commit vs squash vs rebase. Use for: why we squash-merge.
- [Pro Git, ch. 3 "Git Branching"](https://git-scm.com/book/en/v2/Git-Branching-Branches-in-a-Nutshell)
  The free official git book. Use for: what a branch actually is, once the basics feel easy.
- [GitHub CLI manual: `gh pr`](https://cli.github.com/manual/gh_pr)
  Opening, checking out and merging PRs from the terminal. Use for: `gh pr create`, `gh pr checkout`.

## Wisdom (Communities)

- [GitHub Community Discussions](https://github.com/orgs/community/discussions)
  GitHub's official, staff-moderated forum. Use for: "is this normal?" questions about PRs and reviews.
- In-team: post PR links in the team channel and ask for review there. Real reviews from teammates are the fastest feedback loop.
