Glossary

The words every lesson uses, and what they mean on this repo.

Term Meaning
Repository (repo) The project folder plus its full history. Ours is tnamdevnote/project-waymo.
Clone Download a repo to your machine. Done once.
main The shared branch everyone builds from. Only changes merged through a PR land here.
Branch Your own line of work, split off from main. Changes here don't affect anyone until merged.
Pull Bring other people's new commits down to your machine.
Commit A saved snapshot of your changes with a message describing them.
Stage (git add) Choose which changed files go into the next commit.
Push Send your branch's commits up to GitHub.
Pull request (PR) A request to merge your branch into main, with a page for discussion and review.
Diff The line-by-line view of what changed. On a PR it's the Files changed tab.
Review A teammate's feedback on a PR, submitted as Comment, Approve, or Request changes.
Suggested change A review comment with an exact edit the author can commit in one click.
Preview deployment A live web copy of a PR's branch, built by Vercel and linked in a bot comment on the PR.
Merge Bring a branch's changes into main.
Squash and merge Merge a PR as one single commit on main. Our default.
Merge conflict Two branches changed the same lines, and git needs a person to choose. Ask for help.

Definitions follow GitHub's own glossary.
